# Voice Tasks — PWA + Android

Новая экспериментальная версия Voice Tasks на базе стабильной PWA от 13.09.2026.

- По ссылке / как PWA: полный голосовой планировщик без системного будильника.
- В Android APK: тот же интерфейс + нативный системный будильник через Android Bridge.
- Старая стабильная версия VoiceTasks не изменяется.
- Web-часть можно обновлять отдельно от Android Core.

Текущая web-версия: 0.1.3-next.2.
